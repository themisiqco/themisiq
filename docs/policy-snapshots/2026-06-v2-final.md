# ThemisIQ customer-facing policy — snapshot of consent version `2026-06-v2-final`

## Why this file exists

`purchase_consents.consent_version` records **which wording a customer agreed to**. The wording
itself lives only in three React components, which are edited in place — so before this file,
a consent row reading `2026-06-v2-final` resolved to whatever `/terms` happened to render today,
not to what the customer actually saw. This snapshot is the readable document that string points at.

Create a new file in this directory whenever the consent version is bumped. Do not edit this one:
its whole value is that it is the text as it stood, and an edit destroys that.

## Fidelity note

**This is rendered prose extracted by hand from JSX.** There is no generator: the policy text is
JSX literals in three components, and nothing in the repo reads them. `scripts/extract-sources.sh`
is PDF→text for pinned regulatory sources and does not apply.

What was done to the text:

* **HTML entities resolved** — `&mdash;` → —, `&rsquo;` → ’, `&amp;` → &, `&nbsp;` → space.
* **Styling and navigation dropped** — inline styles, the sticky table of contents, section anchors,
  scroll-spy state and the `<Section>` / `<BulletItem>` wrappers. Tables are reproduced as tables.
* **Section order and wording are otherwise unchanged.** Nothing was normalised, shortened,
  corrected or reordered. Where a section interleaves prose and bullets, the source order is kept
  (Terms §6 and §11 both close with a paragraph AFTER their bullet list).

Two things a naive extraction would get wrong, recorded so a future reader can check them:

* **Refund Policy §6 "Contact" is a styled callout, not body prose.** It is not a `<p style={body}>`
  and is skipped by any extractor keyed on that pattern. It was read from source and is included below.
* **Terms §5 references "Part C (Checkout Consent)", which does not exist as a page in this repo.**
  There is no `/consent` route and no Part C document. The consent wording a customer actually sees
  is the three checkboxes in `app/components/ConsentForm.tsx`, reproduced at the end of this file.

The Terms and Privacy pages carry an intro callout above their first section; both are included.
